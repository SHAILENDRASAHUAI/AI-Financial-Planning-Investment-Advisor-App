# Smart Wealth Planner AI

Smart Wealth Planner AI is an educational AI-powered financial planning and investment assistant with:

- **Frontend:** Flutter + Riverpod + FL Chart
- **Backend:** FastAPI (Python)
- **Database target:** PostgreSQL (ready for persistence wiring)
- **Financial data:** Yahoo Finance (`yfinance`)

## Core capabilities implemented

- Guided financial profile intake schema (personal, income, housing, loans, children expenses, monthly expenses, investments, goals)
- Risk assessment classification (Conservative/Moderate/Aggressive)
- Financial analysis engine:
  - income/expense/debt evaluation
  - monthly surplus calculation
  - health/debt/savings/readiness scores
- Personalized allocation recommendations by risk profile
- Portfolio templates (Conservative/Moderate/Aggressive)
- Market research endpoint backed by Yahoo Finance
- AI coach response scaffolding for **English**, **Hindi**, and **Hinglish**
- SIP and Loan calculators
- Mandatory disclaimer in API and app UI
- GitHub Actions for tests/lint and Android APK/AAB builds with uploaded artifacts

## Important Disclaimer

> Investment recommendations are educational estimates generated by AI and historical market data. They are not guaranteed financial advice. Users should perform their own research or consult a qualified financial advisor before making investment decisions.

## Backend quick start

```bash
cd backend
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
uvicorn app.main:app --reload
```

## API endpoints

- `GET /api/v1/health`
- `POST /api/v1/analysis`
- `POST /api/v1/market-research`
- `POST /api/v1/portfolio`
- `POST /api/v1/coach`
- `POST /api/v1/calculators/sip`
- `POST /api/v1/calculators/loan`
- `POST /api/v1/goals/progress`

## Frontend quick start

```bash
cd frontend
flutter pub get
flutter run
```
